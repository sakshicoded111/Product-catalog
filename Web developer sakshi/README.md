# Product Catalog

A simple single-page product catalog website built with pure HTML.

## Features
- Clickable navigation links that scroll to each product section
- Sections for Electronics, Snacks, and Skincare
- Each product includes an image, description, price, and purchase link

## Tech Used
- HTML5

## How to View
1. Clone or download this repository
2. Open `index.html` in any web browser
